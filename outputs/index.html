Arquitectura

Tres módulos. Un flujo claro.

Cada componente cumple una función acotada: observar, interpretar y orientar.

Captura→Análisis→Consejo
01

capture.py

Obtiene imágenes de la pantalla con mss para analizarlas localmente.

02

analyzer.py

Procesa la imagen con OpenCV y OCR para estimar efectivo, vida y oleada.

03

advisor.py

Evalúa las lecturas disponibles y presenta recomendaciones en pantalla o consola.

Instalación

Arranca en tres pasos.

Clona el proyecto, instala sus dependencias y ejecuta el analizador.

1 · Clona el repositorio

git clone https://github.com/tu-usuario/tdx-strategy-vision-ai.git
cd tdx-strategy-vision-ai

2 · Instala dependencias

python -m pip install -r requirements.txt

3 · Inicia el analizador

python main.py

Si usas Tesseract OCR, instala también el programa Tesseract en tu sistema y configura su ruta ejecutable en el proyecto.
